# V22 Golden Scene visual rejection

## Decision

The nine current golden-scene compositions are **not accepted as the visual direction for the CLM AI Knowledge Hub**.

They remain useful as semantic and reasoning experiments. Their shared presentation grammar should not be propagated into production.

## Why they miss the bar

### 1. The directions are not visually independent enough

Overview A/B/C, Knowledge A/B/C and Change A/B/C use different explanatory geometries, but most still share the same visual language:

- cream/beige background;
- dark green + pale sage;
- thin hairline connectors;
- small editorial labels;
- restrained white/green artifact cards;
- similar typography scale and spacing behaviour.

The result is nine variations inside one conservative design system rather than nine genuinely different art-direction hypotheses.

### 2. The 1920×1200 canvas is underused

Many compositions place a relatively small diagram in a large quiet field. This reads as refined presentation design rather than a high-end interactive information product.

The strongest supplied references use the full canvas to create simultaneous context, large visual anchors, cropping, material depth and stronger spatial tension.

### 3. Too much meaning is still carried by small text

Several scenes require the reader to read numerous tiny labels, explanatory notes or card copy before the mechanism becomes clear.

That reverses the intended hierarchy. The primary relationship should be visually inferable first; text should clarify, qualify and expose exact meaning afterwards.

### 4. The work is still too abstract

The scenes frequently rely on boxes, planes, arrows and generic labels. They do not yet contain enough recognisable CLM work artifacts, document fragments, source/evidence objects, annotations, system surfaces or concrete work-state material.

The references feel authored because their visual objects appear to come from a real world of work. The current golden scenes still look like diagrams about that world.

### 5. Typography is not doing enough compositional work

Headlines and labels are elegant but mostly sit around the diagrams. The strongest reference work uses type scale, cropping, rhythm and alignment as part of the visual architecture itself.

### 6. Interaction exists but does not yet transform understanding enough

The browser-tested controls are semantically useful, but most interactions currently change state, emphasis or selection inside a fundamentally static composition.

The next bar is stronger: interaction should visibly reconfigure the explanatory scene so that a relationship, constraint, responsibility boundary or consequence becomes easier to understand.

### 7. The visual identity is too uniform and too safe

The current restraint creates coherence, but at the cost of memorability. The product needs calm analytical trust without becoming visually timid.

The references demonstrate that a regulated-bank product can still use strong scale, unusual composition, bespoke illustration and spatial interaction while remaining serious.

## What is worth preserving

Do not discard the semantic discoveries.

Useful mechanisms from the current scenes include:

- Run / Develop / Govern-change as representative work routes;
- a visible human-review seam;
- separate reuse/applicability review;
- meaning / scope / provenance staying attached;
- context selection as a bounded task aperture;
- version fault lines;
- candidate impact paths rather than automatic propagation;
- historical evidence pinned to the version/scope it covered;
- operating conditions such as supplied input, interface, permission and write route remaining distinct.

These are **semantic assets**, not visual templates.

## Reset for the next Astra pass

Do not refine all nine compositions.

Start with one story: **Useful work first**.

Produce three genuinely independent art-direction hypotheses that differ in medium and architecture:

1. immersive / editorial / spatial;
2. recognisable-work / artifact-led;
3. analytical / interactive / inspectable.

One direction must become good enough to stand beside the supplied references before the other two stories are developed.

## Acceptance question

For every candidate screenshot ask two separate questions:

1. **Visual:** would this plausibly sit among the strongest supplied reference images?
2. **Semantic:** does it preserve the required distinctions without corrective fine print?

Both must pass independently.
