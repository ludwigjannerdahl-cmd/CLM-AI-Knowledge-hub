# V22 Reference Web Research

Date: 2026-10-15

This report records public-web evidence used to structure the reference atlas. It is not CLM factual authority.

## Research libraries

- Land-book provides hand-picked website inspiration with filters including industry, style, type and typography. This supports deliberate reference selection instead of vague aesthetic browsing.
- Lapa Ninja provides thousands of landing pages plus full-page screenshots and recordings, making it useful for page rhythm and interaction study.
- Mobbin positions itself as a large shipped mobile/web design-reference library with screens, flows, animations and UI elements; useful for analytical product ergonomics.
- SaaSFrame combines website/product screens, flows, responsive versions and Figma access; useful as a bridge between authored web composition and product UI.
- Page Flows focuses on real-world user flows plus screen recordings/annotations; useful for state-transition and interaction research.
- SiteInspire curates high-end design across typographic, art-direction, grid, minimal and unusual-layout categories.
- One Page Love curates one-page sites, templates and section examples; useful for long-scroll narrative economy.
- Awwwards provides interaction-design and technology categories including animation, WebGL, 3D and unusual navigation; useful selectively for interaction techniques.

## Direct references

- Initiate Architecture uses mouse-based exploration and a full-canvas composition; useful for spatial authorship.
- pen.dev presents an agentic visual canvas with design/code interoperability, browser import, SVG paths, shaders and code-on-canvas; useful as a process reference for composition-first work.
- EigenPal describes document workflows with human checkpoints, logged/reversible actions, permission-aware cited search and evaluation on historical data; useful for trust/evidence integration.
- Cohere North uses large product surfaces and restrained surrounding composition to explain enterprise AI capabilities; useful for balancing product proof and editorial hierarchy.
- Invisible's 'How we work' material places validation and measurement within the workflow narrative; useful for evidence/evaluation storytelling.
- Lokalise's project editor and screenshot linking keep object/context/metadata together; useful for simultaneous inspection.
- Atticus combines editorial clarity with explicit scope/legal boundary statements; useful for making qualifiers primary information rather than footnotes.
- Weave Bio frames AI-enabled regulatory knowledge work around expert scrutiny and a knowledge lifecycle; useful as a high-stakes human-ownership analogue.

## Design conclusion

The research supports three coexisting product modes:

1. editorial / explanatory;
2. spatial / interactive;
3. analytical workspace.

The previous V22 runtime over-indexed on analytical workspace patterns. The golden-scene sprint should prove stronger integration of all three before production propagation.
