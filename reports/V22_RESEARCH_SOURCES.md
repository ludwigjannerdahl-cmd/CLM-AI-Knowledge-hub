# External research sources for V22

These sources inform design method only. They do not establish CLM facts.

## Layout and composition
- IBM Design Language — Layout overview: https://www.ibm.com/design/language/layout/overview/
- IBM Design Language — Layout tips and techniques: https://www.ibm.com/design/language/layout/tips-and-techniques/

Useful principles: focal hierarchy, balanced asymmetry, negative space, structural/editorial rhythm, repetition plus variation, deliberate eye movement.

## Technical diagrams
- IBM Design Language — Technical diagrams: https://www.ibm.com/design/language/infographics/technical-diagrams/design/

Useful principles: explicit node/connector semantics, legibility, consistent notation, diagram type chosen for the question.

## Complex information and progressive disclosure
- Nielsen Norman Group — Progressive Disclosure: https://www.nngroup.com/articles/progressive-disclosure/
- Nielsen Norman Group — 8 Design Guidelines for Complex Applications: https://www.nngroup.com/articles/complex-application-design/

Useful principles: primary path first, secondary detail on demand, easy transition between levels, salient important information, reduce competition rather than merely adding emphasis.

## Density and layout regimes
- Carbon Design System — 2x Grid: https://www.carbondesignsystem.com/building-blocks/foundations/2x-grid/guidelines
- Carbon Design System — Data table: https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines

Useful principles: editorial, docs/product and high-density layouts can coexist within one system; tables are efficient for scanning but not a universal representation.

## Astra capability and validation
- GPT-6 Astra model: https://developers.openai.com/api/docs/models/gpt-6-astra
- OpenAI prompt engineering guidance: https://developers.openai.com/api/docs/guides/prompt-engineering
- Building games with Astra: https://developers.openai.com/blog/how-to-build-games-with-astra

Useful principles: strong front-end/coding capability, plan thoroughly, use browser/testing feedback, and let visual review complement automated correctness checks.
