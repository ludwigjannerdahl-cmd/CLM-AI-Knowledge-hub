## Implementation

The source remains plain HTML/CSS/JavaScript with deterministic components. `coherence.css` establishes desktop width regimes and shared reading geometry. Deep introductions use title and explanation side by side; prose retains a constrained measure. Requirements use distinct source/requirement/test forms. Evidence puts actual recorded fields before optional process depth. Source and object reading keep authority beside the material. Topic typography, tables and retained fragments follow the same spacing and hierarchy. Search keeps typed lexical discovery and a wider results measure. Design Lab is preserved as infrastructure and not promoted into primary navigation.

No new internal facts, ownership, readiness claims or font files are added. Existing canonical objects, source versions, text corpora and scoping engine remain the factual basis. Rendered and reader acceptance must be recorded separately below after the final run.
