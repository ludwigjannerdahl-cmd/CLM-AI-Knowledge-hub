# Composition review

One review file per golden scene belongs here after A/B/C renders exist:

- `overview.md`
- `knowledge.md`
- `change.md`

Each review must:

1. name the active references and their intended lesson;
2. compare A/B/C on composition rather than pixel similarity;
3. explicitly reject at least one direction;
4. identify the largest remaining visual gap in the strongest direction;
5. identify the strongest semantic false-inference risk;
6. specify one large revision move;
7. point to the revised 1920×1200 render;
8. state whether the scene is nominated or still exploratory.

A browser-pass result alone is never visual acceptance.
