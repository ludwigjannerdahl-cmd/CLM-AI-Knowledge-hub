# V22 Design Decision Log

## 2026-10-15 — reject CSS-only visual ambition as the primary method

Decision: the earlier V22 runtime is retained as semantic/technical evidence but not accepted as the visual target.

Reason: it remained structurally anchored to V21 and produced refined product UI rather than the authored visual quality of the supplied/generated references.

Consequence: no further broad styling propagation before golden-scene exploration.

## 2026-10-15 — 1920×1200 becomes canonical desktop canvas

Decision: design the golden scenes for workstation use first.

Reason: the Hub benefits from simultaneous context, relationship and consequence; 1600-wide testing was too conservative as the design centre.

Consequence: 1600/1440/tablet/mobile become later projections.

## 2026-10-15 — skill loading becomes pull-based

Decision: preserve semantic invariants but stop injecting the entire Sensemaking/visualization library into every design task.

Reason: method should expand reasoning when needed, not preselect the visual answer.

## 2026-10-15 — no production presentation code before scene competition

Decision: Overview, Knowledge and Change each require three independent directions, explicit rejection and revision before any reusable grammar is extracted.

Reason: avoid path dependence and premature systematisation.
