# V22 Reference Selection by Golden Scene

Use a small active set per scene. The point is clarity of intent, not maximum inspiration coverage.

## Overview — How AI fits into CLM work

Primary references:
- supplied/generated CLM boards — visual bar and material vocabulary;
- Initiate Architecture — full-canvas spatial authorship;
- Land-book — deliberate macro-composition search;
- Cohere North — large product plane surrounded by restraint;
- Atticus — editorial clarity and visible boundaries.

Optional interaction reference:
- one Awwwards interaction example only if the static composition already works.

Do not use Mobbin/SaaSFrame as the primary visual model for the opening.

## Knowledge — Knowledge becomes usable

Primary references:
- supplied/generated CLM boards — source/structure/execution visual language;
- pen.dev — composition as a manipulable visual artifact, not merely DOM styling;
- Lokalise — simultaneous context beside the interpreted object;
- EigenPal — human checkpoints/evidence within document work;
- Weave Bio — expert ownership across an AI-enabled knowledge lifecycle.

Optional macro reference:
- Land-book or SiteInspire for composition, but only one.

## Change — A change propagates

Primary references:
- supplied/generated CLM boards — aligned change/impact/evidence concepts;
- EigenPal — reversible/human-reviewed workflow;
- Lokalise — contextual object inspection;
- Invisible — validation as part of the operating mechanism;
- Page Flows — state transition research for expand/inspect/review interactions.

Optional interaction reference:
- one Awwwards example if it helps make propagation or version switching more understandable.

## Later propagation

- Mobbin: source reader, search, evidence inspector, object detail, history.
- SaaSFrame: analytical workspace layouts and responsive product patterns.
- Lapa Ninja: full-page rhythm after golden scenes are accepted.
- One Page Love: long-scroll narrative economy and section sequencing.
- SiteInspire: secondary editorial/art-direction search.

Do not load all references into one design task.
