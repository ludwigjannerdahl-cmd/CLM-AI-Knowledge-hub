# V22 Composition Render Requirements

The composition sprint is reviewed on real browser renders, not source inspection.

## Canonical capture

- viewport: 1920×1200
- browser scale: 100%
- first-frame screenshot required
- full-page screenshot optional when scroll/pacing is part of the concept
- no page errors
- no horizontal overflow

## Required directions

Nine initial captures are required before selection:

- Overview A / B / C
- Knowledge A / B / C
- Change A / B / C

Then three revised captures are required after critique:

- accepted-candidate Overview
- accepted-candidate Knowledge
- accepted-candidate Change

## Evidence package

Each scene's render artifact should contain:

- A/B/C screenshots;
- direction-note files;
- comparison/review note;
- revised selected render;
- reference-capture metadata used for that scene.

## Important

A render passing browser checks is not visual acceptance. The browser checks only establish that the composition can be inspected reliably.
