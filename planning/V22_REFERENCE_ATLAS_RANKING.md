# V22 Reference Atlas — usage ranking

This ranking is about **fit for the CLM AI Hub**, not general design quality.

## 1. Mobbin — strongest for shipped product ergonomics

Use later for source reading, object detail, search, evidence review, filters, history, contextual inspectors and multi-pane analytical work.

Do not let it define the opening art direction.

## 2. Land-book — strongest for deliberate macro-composition search

Use to find a small number of references by industry/style/type/typography instead of browsing by vague aesthetic similarity.

Best use now: golden-scene macro composition.

## 3. SaaSFrame — strongest bridge between web composition and product UI

Use for product/workspace layouts and responsive projection once the golden scenes are accepted.

## 4. Lapa Ninja — strongest for full-page pacing

Use its full-page captures and recordings to study how a page moves between expressive, quiet and dense sections.

## 5. Page Flows — strongest for state transitions

Use for how interactions reveal more meaning after selection, filtering, review, navigation or state changes.

## 6. SiteInspire — secondary art-direction library

Use for high-end typographic and unusual-layout references.

## 7. Awwwards — selective interaction frontier

Use for one purposeful interaction/motion technique at a time. Do not use as the global product model.

## One Page Love — useful but narrower

Use for long-scroll narrative economy and section sequencing; lower priority for the core analytical workspace.

## Direct-site references override the ranking when the lesson is specific

- Initiate Architecture: full-canvas spatial authorship.
- pen.dev: design/code as one visual-canvas workflow.
- EigenPal: human checkpoints/evidence/reversibility inside the work surface.
- Lokalise: simultaneous context and inspectability.
- Cohere North: large product planes with restrained surrounding chrome.
- Invisible: evidence/validation as part of the work mechanism.
- Atticus: high-stakes editorial clarity and explicit boundaries.
- Weave Bio: expert ownership through an AI-enabled knowledge lifecycle.

The ranking is a search priority, not a mandate to use every source.
