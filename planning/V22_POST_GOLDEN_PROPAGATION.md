# V22 Post-Golden Propagation

This file is intentionally deferred until the three golden scenes are accepted.

The purpose is to stop the team from predefining a design system before the strongest compositions exist.

After Overview, Knowledge and Change each have one accepted 1920×1200 composition:

1. extract only the visual principles that recur naturally across the accepted work;
2. separate identity-level grammar from scene-specific geometry;
3. test the extracted grammar on one dense analytical surface before broad propagation;
4. then propagate deliberately into:
   - source reader / provenance;
   - search and contextual discovery;
   - evidence / evaluation;
   - object detail;
   - operating conditions;
   - relationship explorer;
   - portfolio / value views;
5. preserve the right for a surface to use a different native representation when its reasoning task differs.

Do not assume the final grammar is known in advance.

Potential later reasoning jobs that may deserve dedicated representations include:

- human / AI / authority boundaries;
- task swimlanes;
- uncertainty overlays;
- dependency / impact graphs;
- control / barrier reasoning;
- temporal version history;
- counterfactual operating scenarios;
- evaluation pipelines;
- value-to-capability dependencies.

These are candidate reasoning needs, not a required diagram checklist.
