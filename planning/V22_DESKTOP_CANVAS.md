# V22 Desktop Canvas Contract

Primary design target: **1920×1200 at 100% browser scale**.

The Hub is primarily a desktop reasoning product. Responsive projections remain required later, but the golden-scene design centre is a workstation canvas with enough width to show context, relationship and consequence simultaneously.

## Use of width

Avoid centring a narrow marketing column inside 1920 px.

Useful composition archetypes include, but are not limited to:

- editorial framing + dominant reasoning canvas;
- source/context + primary visual + inspector;
- full-width spatial scene with local annotations;
- sticky narrative text + evolving visual plane;
- aligned comparison + downstream impact field.

These are not fixed grids.

## First-frame target

The first 1920×1200 frame should behave like a composed analytical poster/workspace:

- one dominant idea;
- readable hierarchy at normal viewing distance;
- enough simultaneous context to reduce mental backtracking;
- no tiny diagrams surrounded by unused space;
- no requirement to read long body copy before the visual becomes meaningful.

## Compatibility after acceptance

After the golden scenes are accepted, test at least:

- 1600×1000 or equivalent desktop;
- 1440-class laptop;
- tablet;
- mobile.

Responsive design should preserve semantic order rather than shrink the desktop geometry.
